# WebtoonFlow AI Frontend

웹툰 연재 작가 및 크리에이터를 위한 창작 설계 + 일정 리스크 예측 웹서비스 프론트엔드 시제품입니다.

## 현재 구현 방향

- 웹 기반 온라인 서비스를 전제로 설계했습니다.
- 현재 단계에서는 백엔드가 없으므로 mock/localStorage 기반으로 동작합니다.
- 추후 FastAPI 백엔드가 완성되면 `src/api/*` 파일의 mock 함수를 실제 API 호출로 교체하면 됩니다.
- AI는 이미지 생성이 아니라 스토리 구조 제안, 장면 설계, 설정 충돌 설명 등 텍스트 기반 보조 기능으로 연결하는 방향입니다.

## 이번 수정 반영 사항

- 새 프로젝트 생성 화면을 단일 페이지 폼으로 유지하되, 기본 정보 / 작업 환경 / 스토리 개요 섹션으로 정리
- 숫자 입력은 input + `+`, `-` 버튼 방식 사용
- 채색 방식, 배경 복잡도는 라디오 버튼 방식 사용
- 어시스턴트 유무는 토글 스위치 방식 사용
- 일정 리스크 화면에 마감 성공 확률 계산 기준 설명 추가
- 배경 복잡도 기준 설명 추가
- `현재 계획으로 계산하기`와 `계획 조정 미리보기(What-if)`의 역할 분리
- 캐릭터 카드 클릭 시 상세/수정 모달이 열리도록 변경
- 캐릭터 입력 placeholder 보강

## 실행 방법

```bash
npm install
npm run dev
```
